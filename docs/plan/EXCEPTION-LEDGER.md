# EXCEPTION-LEDGER — 特例運用で省略・バイパスした事項の台帳

デモや期限のために、実装・試験・安全の一部を期間限定で省略・バイパスしたときに記録する。
**ここに記録の無い省略・バイパスをしてはいけない。未クローズが何かはこの台帳が唯一の正。**

**2026-10-06 時点で未クローズ 1 件（`W-1`）。**

## 書き方

- 特例を始めるときは、**ユーザーの指示**と日付・対象範囲・期限を先に書く。
- 省略・バイパスした箇所ごとに 1 行。ID は `W-<番号>`。
- **コード側には `WAIVER(demo): W-<番号> <一言>` のコメントを必ず置く。**台帳とコードのタグは 1 対 1。
  `grep -rn 'WAIVER(demo)'` の結果と台帳の未クローズ行が一致しなければ、どちらかが間違っている。
- クローズしたら行を消さず、状態を「クローズ」にしてコミットハッシュを書く。

## 特例でも無効化しないこと（解除不可）

2026-10-06 に埋めた（v2）。**上端の検知を一時無効にしている（`W-1`）間、残った守りはこれだけ**なので、どれも外さない。

| 守り | 出どころ |
| --- | --- |
| 物理非常停止（th-system のボタンで昇降機の電源が切れる） | spec [Spec-safety.md](spec/Spec-safety.md) §4 |
| 通信断での自動停止（ウォッチドッグ。昇降部・カメラモジュールの Arduino の両方） | spec [Spec-module.md](spec/Spec-module.md) §2 |

| 距離計を持つ上部モジュールからの操作での天井（値が無い・古いときに上昇しないことを含む） | spec [Spec-safety.md](spec/Spec-safety.md) §2 #3〜#4 |
