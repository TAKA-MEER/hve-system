# EXCEPTION-LEDGER — 特例運用で省略・バイパスした事項の台帳

デモや期限のために、実装・試験・安全の一部を期間限定で省略・バイパスしたときに記録する。
**ここに記録の無い省略・バイパスをしてはいけない。未クローズが何かはこの台帳が唯一の正。**

**2026-09-25 時点で記録なし。**

## 書き方

- 特例を始めるときは、**ユーザーの指示**と日付・対象範囲・期限を先に書く。
- 省略・バイパスした箇所ごとに 1 行。ID は `W-<番号>`。
- **コード側には `WAIVER(demo): W-<番号> <一言>` のコメントを必ず置く。**台帳とコードのタグは 1 対 1。
  `grep -rn 'WAIVER(demo)'` の結果と台帳の未クローズ行が一致しなければ、どちらかが間違っている。
- クローズしたら行を消さず、状態を「クローズ」にしてコミットハッシュを書く。

## 特例でも無効化しないこと（解除不可）

設計が固まったら埋める。少なくとも**物理非常停止**と**通信断での自動停止（ウォッチドッグ）**は、
先行試作の段階から外していないので、ここに載せる前提で設計する。
