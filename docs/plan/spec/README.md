## 1. 位置づけ

| 文書 | 役割 |
| --- | --- |
| **`docs/plan/spec/`（ここ）** | **完成形の正本。**何が・どう振る舞うべきか。**確定した方針はここが正** |
| `docs/plan/detailed/` | **詳細設計書。**ノード名・トピック名・ピン・ファイル構成・アルゴリズム・作業パケット |
| `docs/plan/archive/v1/` | 旧版の spec・detailed。**参照のみ** |
| `CLAUDE.md`（リポジトリ直下） | 作業のしかた・環境の癖・コードの不変ルール |
| `docs/plan/`（上記以外） | **未確定の検討メモ。**`spec/` を上書きしない |

方針を変えるときは `CLAUDE.md`「方針変更時のルール」に従い、**コードを触る前にここを更新する。**

### 1.1 書かないもの

本設計書は**詳細設計の入力**である。ノード名・トピック名・ピン番号・フレーム形式・ライブラリ・
ファイル構成・実装技術・アルゴリズムの実装方法は書かない（`detailed/` の役割）。
書くのは「**何が・どう振る舞うべきか**」と「**どういう値が要るか**」だけである。

### 1.2 どこに何が書いてあるか

| 知りたいこと | 見る文書 |
| --- | --- |
| 対象・目標・範囲・構成 | [Spec.md](Spec.md) |
| **何が決まっていないか** | [Spec-open.md](Spec-open.md) §2 |
| 旧版で決めたこと・分かったこと | [archive/v1/spec/Spec-open.md](../archive/v1/spec/Spec-open.md) |
| 先行試作・外部資料 | [source/README.md](../source/README.md) |
| ノード名・ピン・作業パケット | [詳細設計書](../detailed/README.md) |
