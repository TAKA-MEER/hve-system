# Spec-open — 未確定事項・決定の記録（v2）

[Spec.md](Spec.md) の詳細。**何が決まっていないか**はここが正。
決まったら §3 に 1 行記録し、該当する Spec ファイルへ反映してから §2 の行を消す。

ID の付け方は旧版と同じ `H-<分類><番号>`（[archive/v1/spec/Spec-open.md](../archive/v1/spec/Spec-open.md)）。
**旧版の ID は意味を変えずに引き継ぎ、v2 で新しく出た問いは旧版の続きの番号を振る。**
分類は旧版の `G`・`S`・`A`・`V`・`X`・`U` に、`M`（昇降部と上部モジュールの取り決め）を足す。
**領域ごとの Spec ファイルに書いた未確定事項は、そのファイルの「未確定」節が正**（[Spec-safety.md](Spec-safety.md) §3・[Spec-ui.md](Spec-ui.md) §3・[Spec-module.md](Spec-module.md) §5）。

| **`H-V1`** | 盤上部の高さの範囲 |
