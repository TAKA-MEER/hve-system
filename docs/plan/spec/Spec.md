## 1. 対象

配電盤上部を確認するロボットのうち、**カメラを盤上部へ持っていき、向け、映すまで**のすべて。
本システムは th-system の走行部に載って運ばれるが、**th-system とは独立したシステム**である（§4 `HD-1`）。

| 担当 | 範囲 |
| --- | --- |
| **本システム** | 昇降機による**高さ**、カメラの**ヨー・ピッチ**、映像の表示、それらの操作画面 |
| th-system | 保管場所⇔試験場の移動、盤前への移動・停止、盤前での位置の微調整、機体の非常停止 |

th-system 側でも、カメラ昇降のピッチ・ヨー・高さは範囲外（別担当）とされている
（th-system [Spec.md](../../../../th-system/docs/plan/spec/Spec.md) §1・[Spec-onsite.md](../../../../th-system/docs/plan/spec/Spec-onsite.md) §7.1）。

**撮影した画像の保存・一覧までを含むかは未定**（[Spec-open.md](Spec-open.md) `H-S2`）。

### 1.1 指示を受ける相手（2026-11-01 ユーザー決定）

**操作者の画面のほか、fk-system（測定機能）と ss-system（画像認識）からも指示を受ける**（fk-system からの申し送り。fk-system [Spec.md](../../../../fk-system/docs/plan/spec/Spec.md) `FD-10`・`FD-11`）。
走行の指示は fk-system が出し、本システムは走行を指示しない。**th-system とは今までどおり直接やり取りしない**（§4 `HD-1` は変えない）。
**fk-system からの操作はいつでも受け付ける。指示を受けるモードは設けない**（2026-11-01 ユーザー決定）。人の操作とぶつかったときは最後の操作が勝つ（[Spec-module.md](Spec-module.md) §4）。

| 相手 | 動かすもの | 本システムが渡すもの |
| --- | --- | --- |
| fk-system | **昇降機**（測定機構の上下）。**測るときは測定機構（アームの制御器）が昇降機とドラムを動かす**（[Spec-module.md](Spec-module.md) §5） | 昇降の状態 |
| ss-system | **昇降機とカメラ（ヨー・ピッチ）**（天面の走査・画角の調整・配置図のための上昇） | 昇降の状態・**静止画**（ss-system が必要なときだけ要求する、倍率に関係なく全体が写る最高解像度の 1 枚。[Spec-ui.md](Spec-ui.md) §1.5.1。**常に流す映像は渡さない**。2026-11-01 ユーザー決定 `H-A12`） |

fk-system・ss-system は**上部モジュールとして昇降部に繋ぐ**（[Spec-module.md](Spec-module.md) §1）。命令はどこから来ても同じ安全の判定を通る（[Spec-safety.md](Spec-safety.md) §2）。
**ss-system が昇降機を動かしている間に fk-system が動かさないよう気をつけるのは fk-system**（fk-system `FD-11`）。本システムは両者の順番を決めない。
**測定機構（fk-system の持ち物）は昇降機に取り付き、カメラモジュールと一緒に上下する**（§5）。
**測定機構の腕を起こすドラムは、昇降部が昇降機に合わせて動かす**（2026-11-01 ユーザー決定。§4 `HD-4`・[Spec-module.md](Spec-module.md) §5）。

## 2. 用語

th-system [Spec.md](../../../../th-system/docs/plan/spec/Spec.md) §2 の用語（機体・試験員・試験場・盤 など）をそのまま使う。
ここには本システムで新たに要る語だけを足す。

| 用語 | 意味 |
| --- | --- |
| 昇降機 | 機体に載り、上部モジュールを上下させる機構 |
| 昇降部 | 昇降機とそれを動かす電子回路。**単体で動かせる**（測定機構が付いていなければ。§4 `HD-4`） |
| 上部モジュール | 昇降部に繋いで**昇降を命じ**、昇降部の状態を受け取るもの。**交換できる**（ソフトウェアごと）。昇降機に載るか（カメラモジュール）は問わず、**fk-system・ss-system も上部モジュールとして繋ぐ**。**同時に複数繋げる**（2026-11-01 ユーザー決定。[Spec-module.md](Spec-module.md) §1） |
| カメラモジュール | 上部モジュールのうち、カメラを載せてヨー・ピッチを動かせるもの。**いま作るのはこれだけ** |
| 操作者 | 本システムを操作する人。th-system の試験員と同じ人かは問わない |
| 移動システム | th-system のこと |
| 測定機構 | fk-system の持ち物。昇降機に取り付き、カメラモジュールと一緒に上下する。測定器を前後に動かせる（fk-system [Spec.md](../../../../fk-system/docs/plan/spec/Spec.md) §1.3）。いまの仮の構成では、腕は昇降機の上端を支点に回り、腕を起こすドラムは機体側に付く（fk-system [arm.md](../../../../fk-system/docs/plan/arm.md)） |
| ドラム | 測定機構の腕を起こす線を巻き取る機構。**機体側（昇降しない側）に付き、昇降部が動かす**（2026-11-01 ユーザー決定。いまの仮の構成。[Spec-module.md](Spec-module.md) §5） |
| アームの制御器 | 測定機構の制御器。腕の根元に置く（fk-system の持ち物） |

## 4. 設計思想

記号は `HD-n`（th-system の `SD-n` と区別する）。

* **HD-1 th-system から独立させる。**互いの仕様変更が波及しないようにする。**th-system とは通信しない**
  （どうしても要るときも最低限にし、先にここを更新する）。走行禁止などの**連動も設けない**。
  共有するのは機体（載せてもらう）と無線 AP だけ
* **HD-2 操作画面は th-system と別に持つ**
* **HD-3 高さは人、または指示を出すシステム（fk-system・ss-system）が映像を見て決める。**盤ごとの高さを事前に登録・計測する仕組みを前提にしない（§6）。
  2026-11-01 ユーザー決定で「人が」から広げた（§1.1）
* **HD-4 上部はソフトウェアごと交換できるモジュールにする。昇降部は単体で動かせる。**（2026-10-06 ユーザー決定）
  昇降部は自分の操作画面を持ち、上部モジュールが無くても昇降できる。
  上部モジュールは昇降部に**昇降を命じ**、昇降部から**状態（センサの値など）を受け取る**。
  **昇降部と上部モジュールの間の取り決めは [Spec-module.md](Spec-module.md)。**
  カメラモジュールを別の機能の機器に替えても、昇降部は作り直さない。
  **上部モジュールがあれば、昇降部の画面を開かなくてもすべての操作ができる**（2026-10-06 ユーザー決定）。
  例外は測定機構のコネクタの確認で、昇降部の画面でだけできる（2026-11-01 ユーザー決定。[Spec-module.md](Spec-module.md) §5）
  **2026-11-01 ユーザー決定で改めた: 測定機構（fk-system）の腕を起こすドラムは、昇降部が昇降機に合わせて動かす。**
  測定機構は、上部モジュールとして繋ぐ部分のほかに、昇降部に直接つなぐ部分（ドラム・コネクタ）を持ち、上部モジュールの枠に収まらないため。
  **測定機構が付いていなければ、今までどおり単体で動かせる。**付いているのにアームの制御器と通信できないときは、昇降機を動かさない（[Spec-module.md](Spec-module.md) §5・[Spec-safety.md](Spec-safety.md) §2 #4e）。
  ドラムの寸法など測定機構に依る値は設定で変えられるようにし、測定機構が変わってもファームを作り直さずに済むようにする（2026-11-01 の提案）

**HD-1 の帰結として受け入れていること:**

| 帰結 | 扱い |
| --- | --- |
| th-system の**画面の**非常停止では昇降機は止まらない | 受け入れる。**物理非常停止ボタンは電源系統を共有しているので昇降機も止まる**（信号のやり取りではなく電源の共有。[Spec-safety.md](Spec-safety.md) §4） |
| 昇降機が上がったまま機体が走れる | 既知のリスクとして残す（[archive/v1/spec/Spec-open.md](../archive/v1/spec/Spec-open.md) §1）。fk-system が走行を指示する間は、fk-system が昇降部の状態を読んで守る（fk-system `FK-X1`） |
| AP を共有するので、映像が th-system の無線を圧迫しうる | 「干渉しない」を守るため映像の上限を決めて確かめる（`H-A8`） |

## 5. 全体構成

| 構成要素 | 中身 | 役割 |
| --- | --- | --- |
| **昇降部** | **旧版と同じ**（2026-10-06 ユーザー決定）: ESP32 ＋ モータドライバ Cytron MD10C ＋ 昇降機のモータ（**パワーウィンドウモータ**） ＋ **下端リミットスイッチ**。ただし**昇降の高さは、昇降機を引き上げるロープの巻き取り機構につないだロータリエンコーダ E6A2-CW3C で測る**（旧版の超音波距離計 HC-SR04 から切り替え。2026-10-15 ユーザー決定）。**上昇・下降の速さもこのエンコーダで測って一定に保つ**（2026-10-15 ユーザー決定。[Spec-ui.md](Spec-ui.md) §1）。**上端はこの高さで検知する**（`H-X9`。実装と実機確認が済むまでは一時無効。[Spec-safety.md](Spec-safety.md) §1.1・§1.2）。**点検用の物理ボタン**（上昇・下降。2026-10-29 ユーザー決定。[Spec-ui.md](Spec-ui.md) §0.3）。**測定機構の腕を起こすドラム（モータと駆動回路）・測定機構のコネクタと、つながったことの検知・アームの制御器との通信**（2026-11-01 ユーザー決定。機器は未定。[Spec-module.md](Spec-module.md) §5） | 上部モジュールを上下させる。**自分の操作画面を出す**。**測定機構が付いているときは、ドラムを昇降機に合わせて動かす** |
| **カメラモジュール**（上部モジュール） | カメラ **M5Stack UnitV2** ＋ **Arduino UNO**（UnitV2 と **UART** でつなぐ） ＋ ヨー用ステッピングモータ **28BYJ-48**（旧版から続投） ＋ ピッチ用サーボ **MG996R** ＋ **天井までの距離計 SRF02**（I2C。旧版と同じ） ＋ 電源は**リチウムイオンのモバイルバッテリ**（2026-10-06 ユーザー決定） | 映像を送り、向きを変え、天井までの距離を測る。**カメラモジュールの操作画面を出す**。**ss-system の指示でもヨー・ピッチを動かし、静止画を渡す**（§1.1）。**ヨーの向きを測れるようにする**（2026-11-01 ユーザー決定。方法は未定 `H-A11`） |
| **測定機構**（fk-system の持ち物） | 未定（fk-system `FK-A5`）。いまの仮の構成は、昇降機の上端を支点に回る腕・腕の根元に置くアームの制御器・機体側のドラム（昇降部が動かす）（fk-system [arm.md](../../../../fk-system/docs/plan/arm.md)）。重さ・最も高い所・電源も未定（`H-V13`） | 昇降機に取り付き、カメラモジュールと一緒に上下する。本システムは**取り付けられるようにする**（2026-11-01 ユーザー決定）。**測るときはアームの制御器が昇降機とドラムを動かす**（[Spec-module.md](Spec-module.md) §5） |
| 無線 | `th-rpi-ap`（th-system のラズパイが出す AP。**将来名前が変わる**） | 操作端末・昇降部・上部モジュールをつなぐ |
| 操作端末 | 未定（`H-A9`） | 昇降部・カメラモジュールの操作画面を開く |

**Arduino がヨー・ピッチのモータを動かし、UnitV2 が Arduino に指令を送る**（2026-10-06 ユーザー決定）。
**操作画面は 2 つある**: 昇降部の画面（昇降だけ）と、カメラモジュールの画面（映像・昇降・ヨー・ピッチ。旧版と同じ）。[Spec-ui.md](Spec-ui.md) §0。
**昇降部のモータは th-system の駆動系と同じ電源系統**で、th-system の物理非常停止ボタンで一緒に電源が切れる。
**測定機構のドラムのモータも同じ電源系統にする**（片方だけ止まると、腕を起こす線が張るか緩むため。2026-11-01 ユーザー決定。[Spec-safety.md](Spec-safety.md) §4）。
AP の名前は将来変わるので、**名前を変えても設定の書き換えだけで済むようにする**。

## 6. 操作の流れ（盤前）

1. th-system が盤前に機体を止める（本システムは関与しない）
2. 操作者がカメラモジュールの画面を開き、**カメラ映像を見ながら昇降機を上昇させる**（速度はスライダーで変える。[Spec-ui.md](Spec-ui.md)）。天井・上端に近づいたら上昇は止まる（[Spec-safety.md](Spec-safety.md)。上端の検知は一時無効）。**電源を入れたあとは、まず一度下端まで下げる**（高さの原点を取る。[Spec-safety.md](Spec-safety.md) §1.2）
3. **操作者がよいと思ったところで止める**
4. 必要ならヨー・ピッチで向きを合わせ、デジタルズームで拡大して盤上部を確認する（[Spec-ui.md](Spec-ui.md) §1.5）
5. 下降させてから、th-system 側で次の盤へ移動する

昇降部の画面は、上部モジュールが無くても昇降機を動かせるようにするためのもの（`HD-4`）。

**fk-system・ss-system が指示するときは、2〜4 を ss-system・fk-system が行う**（天面の走査・画角の調整・測定機構の上下。流れは fk-system [Spec.md](../../../../fk-system/docs/plan/spec/Spec.md) §1.1.1）。
本システムは命令を受けて動かし、状態を返す（§1.1）。

操作を補う工夫（映像の遅延を踏まえた速度の切替・ガイド表示など）の案は
[operation-ideas.md](../operation-ideas.md)（検討メモ。spec ではない）。
