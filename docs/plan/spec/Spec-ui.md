# Spec-ui — 操作画面

[Spec.md](Spec.md) の詳細。th-system とは**別の画面**（[Spec.md](Spec.md) §4 `HD-2`）。

---

## 1. 速度（2026-09-25 ユーザー決定）

**上昇・下降・ピッチ・ヨーの 4 つそれぞれに速度のスライダーを持つ。**速度は可変。

| 項目 | 振る舞い |
| --- | --- |
| スライダーの範囲 | 設定画面で決めた**下限〜上限** |
| スライダーの初期位置 | 設定画面で決めた**初期値** |
| 対象 | **上昇・下降・ピッチ・ヨーの別々に**持つ（上昇と下降も別） |

## 2. 設定画面

| 設定できるもの | 単位 |
| --- | --- |
| 上昇の速度: 下限・上限・初期値 | 未定（`H-U2`） |
| 下降の速度: 下限・上限・初期値 | 同上 |
| ピッチの速度: 下限・上限・初期値 | 同上 |
| ヨーの速度: 下限・上限・初期値 | 同上 |

**守る関係**: 下限 ≦ 初期値 ≦ 上限。満たさない値は保存しない。
