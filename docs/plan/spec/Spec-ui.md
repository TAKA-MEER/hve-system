# Spec-ui — 操作画面

[Spec.md](Spec.md) の詳細。th-system とは**別の画面**（[Spec.md](Spec.md) §4 `HD-2`）。

---

## 0. 画面を出す機器（2026-10-06 ユーザー決定で v2 向けに変更）

**画面は 2 つある。**

| 画面 | 出す機器 | 中身 |
| --- | --- | --- |
| **カメラモジュールの画面** | カメラモジュール | **旧版とほぼ同じで、できることも同じ**（2026-10-06 ユーザー決定）。映像・昇降・ヨー・ピッチ・設定を 1 画面にまとめる。映像を見ながら昇降させる操作（[Spec.md](Spec.md) §6）のため。昇降は昇降部へ命じ、昇降の状態は昇降部から受け取って出す（[Spec-module.md](Spec-module.md)） |
| **昇降部の画面** | 昇降部 | 昇降部を単体で動かすための画面（[Spec.md](Spec.md) §4 `HD-4`）。中身は §0.2。**カメラモジュールがあれば開く必要はない**（昇降部の画面でできることはすべてカメラモジュールの画面でもできる。2026-10-06 ユーザー決定 `H-U8`） |

以下 §1〜§2 は、断りがなければカメラモジュールの画面のこと。

### 0.2 昇降部の画面（2026-10-06 ユーザー決定 `H-U6`）

**カメラモジュールの画面から、映像・ヨー・ピッチ・デジタルズームを除いたもの**とする。

| 持つもの | 振る舞い |
| --- | --- |
| 上昇・下降のボタン | 押している間だけ動く（カメラモジュールの画面と同じ） |
| 上昇・下降の速度スライダー | §1 と同じ |
| 高さ・上下端・天井の扱い・止めた理由の表示 | カメラモジュールの画面と同じ |
| 設定画面 | 上昇・下降の速度の下限・上限・初期値（§2） |

§0.1（スクロールさせない）・§1.6（複数の端末）は、昇降部の画面にも同じに当てる。

### 0.1 スクロールさせない（2026-09-25 ユーザー決定）

**どんな画面の大きさ・向きでも、スクロールが発生しない。**操作画面・設定画面とも、表示領域に収める。

| 項目 | 振る舞い |
| --- | --- |
| 収め方 | 画面全体を表示領域の高さに固定し、映像・ボタン・スライダーを伸び縮みさせる。**部品を画面外やカードの外にはみ出させない** |
| 対応する最小の大きさ | 縦 360×640 ／ 横 640×360（CSS ピクセル）。これより小さい画面は対象外 |
| 押している間だけ動くボタン | どの大きさでも 32×32 以上 |

## 1. 速度（2026-09-25 ユーザー決定）

**上昇・下降・ピッチ・ヨーの 4 つそれぞれに速度のスライダーを持つ。**速度は可変。

| 項目 | 振る舞い |
| --- | --- |
| スライダーの範囲 | 設定画面で決めた**下限〜上限** |
| スライダーの初期位置 | 設定画面で決めた**初期値**。**画面を開くたびに初期値から始まる**（スライダーを動かした値は記録しない） |
| 対象 | **上昇・下降・ピッチ・ヨーの別々に**持つ（上昇と下降も別） |
| 昇降の速度の意味 | **モータドライバ MD10C に与える PWM のデューティ比そのもの。**速度のフィードバックは無い（実際の昇降速度は荷重や電圧で変わる） |

## 1.4 ヨー（2026-09-28 ユーザー決定）

| 項目 | 振る舞い |
| --- | --- |
| 回せる範囲 | **制限なし。**カメラモジュールは 360° 回し続けられる |
| 向きの表示 | **出さない。**ヨーの向き（角度）はシステムで扱わない。向きは映像で確かめる |
| 速度 | deg/s（§1・§2） |

## 1.5 デジタルズーム（2026-09-25 ユーザー決定）

**映像を拡大して表示できる（デジタルズーム）。**カメラ側の光学ズームは持たない。

| 項目 | 振る舞い | 状態 |
| --- | --- | --- |
| 拡大するもの | **映像の表示だけ。**昇降・ヨー・ピッチ・安全の判定には一切影響しない | 決定 |
| 拡大の中心 | **映像の中央**（ガイド線の十字の中心と一致） | 決定 |
| 拡大中に見る場所を変える | **ヨー・ピッチでカメラを向けて変える。**拡大した映像の中を指でずらす操作（パン）は持たない | 決定 |
| 倍率 | 1 倍〜上限（仮 4 倍）。「＋」「−」で段階的に変え、「1 倍に戻す」で戻す。今の倍率を映像の上に常に出す | 決定 |
| 画面を開いたとき | **1 倍から始まる**（スライダーと同じく、前回の倍率を覚えない） | 決定 |
| 拡大のしかた | **カメラモジュールが、カメラの高い解像度の映像から中央を切り出して送る。**拡大しても送る映像の大きさ（無線の帯域）は変わらず、カメラの解像度が許す倍率までは細かさが保たれる | 旧版で決定。**送る映像は 480p**（2026-10-06 ユーザー）。**切り出し元は 720p（1280×720）。細かさが保たれるのは 1.5 倍まで**で、それより上は拡大するほど粗くなる（2026-10-07 ユーザー決定 `H-V10`。`H-V9` の 1080p の前提は、実機で 1920×1080 が取れなかったので取り下げた） |
| 画質と無線の帯域 | **常に流す映像は 480p のまま、`th-rpi-ap` の帯域の数割に収まる範囲で画質を上げる**（圧縮を弱める）。th-system の通信を圧迫しないことを優先する（`H-A8`） | 2026-10-07 ユーザー決定 `H-V10`。上限の実測は `H-A8` |
| 倍率は全端末で共通 | 映像は 1 本なので、倍率は**画面を開いている全端末で共通**。画面を開くと 1 倍に戻る（他の端末の倍率も戻る） | 決定（切り出し方式の帰結） |

### 1.5.1 静止画（2026-10-07 ユーザー決定 `H-U9`）

**ボタンを押したときだけ、カメラの最高解像度（720p）の 1 枚を取り寄せて表示する。**常に流す映像の帯域を使わずに細部を見るため。
**ユーザーが決めたのはこの 1 文まで。下の表の細部は 2026-10-07 の提案で、覆ったら直す。**

| 項目 | 振る舞い |
| --- | --- |
| 写る範囲 | **カメラの映像の全体**（デジタルズームの倍率に関係なく、切り出さない） |
| 画質 | カメラが出したそのまま（作り直さない） |
| 出るのは | **押した端末だけ**（ズームの倍率と違い、ほかの端末には出ない） |
| 表示 | 映像の上に重ねて出し、閉じると映像に戻る。表示中も昇降・ヨー・ピッチの操作は効く |
| 保存 | システムとしては持たない（ブラウザの機能で端末に保存するのは妨げない。画像をどこまで扱うかは `H-S2`） |

### 1.5.2 高画質の映像（予備の手段。2026-10-07 ユーザー決定 `H-V11`）

**いまは作らない。**480p ではどうしても足りない場面が出たときのために、手段として残す。

| 項目 | 振る舞い |
| --- | --- |
| 中身 | 常に流す映像を、カメラが出す 720p をそのまま送る方式に切り替える（帯域は 480p の数倍。`th-rpi-ap` の帯域の大半を使う） |
| 機能の制限 | **使っている間は th-system の走行系を動かさない。**th-system の通信を圧迫するため |
| 制限の守り方 | **操作者の運用で守る。**本システムは th-system と信号をやり取りせず、走行を止める連動も作らない（`HD-1`）。システムで走行を止めたくなったら、先に `HD-1` を見直す |

## 1.6 複数の端末（2026-09-25 ユーザー決定）

| 項目 | 振る舞い |
| --- | --- |
| 同時に開ける | 開ける（何台でも） |
| 操作がぶつかったとき | **最後の操作が勝つ。**操作権の取り合いは作らない（止めたいときに止められない場面を作らないため） |
| 気づけるようにする | 画面に**いま繋いでいる端末の数**を常に出す。**カメラモジュールの画面には、昇降部の画面を開いている端末の数も別に出す**（昇降部の画面からも昇降できるため。2026-10-06 ユーザー決定 `P-10`） |
| デジタルズームの倍率 | 全端末で共通（§1.5） |

## 2. 設定画面

| 設定できるもの | 単位 |
| --- | --- |
| 上昇の速度: 下限・上限・初期値（カメラモジュールの画面からも変えられる。`H-U8`） | PWM デューティ比 [%] |
| 下降の速度: 下限・上限・初期値（同上） | PWM デューティ比 [%] |
| ピッチの速度: 下限・上限・初期値 | deg/s |
| ヨーの速度: 下限・上限・初期値 | deg/s |

| 項目 | 振る舞い |
| --- | --- |
| 守る関係 | 下限 ≦ 初期値 ≦ 上限。満たさない値は保存しない |
| 保存先 | **機器側に保存する。**端末を替えても、画面を開き直しても、電源を入れ直しても同じ設定になる。**上昇・下降の速度は昇降部、ピッチ・ヨーの速度はカメラモジュール**に保存する（上部モジュールを替えても昇降の設定が残るように。2026-10-06 ユーザー決定 `H-U7`） |
| 触れる人 | **誰でも触れる**（制限しない） |

## 4. モックアップ

[mockup/index.html](mockup/index.html) は**見た目と操作感を確かめるための静的 HTML**（実装ではない）。
ファイルをブラウザで開くだけで動く。外部のフォント・スクリプトを読み込まない。
**この文書と同じ画面構成を持つ。片方を直したらもう片方も直す。**
**旧版から写したもので、カメラモジュールの画面にあたる。**昇降部の画面（§0.2）のモックアップはまだ無い。

モックアップには、**まだ決まっていない**次の要素も載せてある（採否が出たら直す）:

| 要素 | 出どころ | 状態 |
| --- | --- | --- |
| デジタルズームの「＋」「−」「1×」ボタンと倍率表示 | §1.5 | **決定済み**（モックアップはブラウザで絵を拡大しているだけ。見え方は同じ） |
| 映像に重ねるガイド線（十字・枠）と表示切替 | [operation-ideas.md](../operation-ideas.md) 案 4 | 未決定 |
| 高さのゲージと上端の線 | 同 案 5（高さの表示） | 未決定 |
| ヘッダの接続台数 | §1.6 | **決定済み** |
| **静止画のボタンと重ねた表示** | §1.5.1 | **決定済み・モックアップに未反映** |
| 「仮値で動作中」の表示と、設定画面の仮値の一覧 | 詳細設計 `DD-3` | 詳細設計で決定 |
| 停止理由の文言 | 詳細設計の停止理由（[DetailedDesign-names.md](../archive/v1/detailed/DetailedDesign-names.md) §3） | 文言は仮 |

ヘッダの紫の「モック」ボタンは状況（天井が近い・切断など）を再現するためのもので、実装の画面には無い。
確認用に `?h=1100&hold=lift_up`・`?ceil=stale`・`?settings=1`・`?mock=1` のような URL の引数でも状態を作れる。
