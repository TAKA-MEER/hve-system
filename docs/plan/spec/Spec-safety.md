# Spec-safety — 上下端と天井

[Spec.md](Spec.md) の詳細。昇降機を**動かしてはいけない所へ動かさない**ための振る舞い。

---

## 1. 検知手段（2026-09-25 ユーザー決定）

| 守るもの | 検知手段 | 取り付け |
| --- | --- | --- |
| **下端** | **リミットスイッチ** | 昇降機の下端 |
| **上端**（昇降機の可動範囲の上限） | **超音波距離計**（上向き） | 昇降機の**下部から上向き**。上がっていく部分までの距離＝昇降の高さを測る。上端はリミットスイッチを付けられないため |
| **天井** | **超音波距離計**（上向き） | **カメラ部のラズパイ**に付け、カメラ部から天井までの距離を測る |

## 2. 振る舞い

| # | 状況 | 振る舞い |
| --- | --- | --- |
| 1 | 下端のリミットスイッチが押されている | **下降しない。**上昇はできる |
| 2 | 昇降の高さが上端の閾値に達した | **上昇しない。**下降はできる |
| 3 | カメラ部から天井までの距離が閾値を下回った | **上昇しない。**下降はできる |
| 4 | 上端・天井の距離が**読めない・古い**（センサの故障、カメラ部との通信断、カメラ部の電池切れ） | **上昇しない。**下降はできる。画面に理由を出す |
| 5 | 1〜4 で止めたとき | 操作者に**なぜ止まったか**を画面で示す |

**#4 は必須。**天井の距離はカメラ部（ラズパイ）で測り、昇降機を動かすのは昇降部（ESP32）なので、
**無線を挟んだ判定になる**。値が届かないことを「近くない」と扱うと、通信が切れた瞬間に天井へ突っ込む。
