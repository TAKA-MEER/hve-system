# Spec-power — カメラモジュールの電池と外し忘れ

[Spec.md](Spec.md) §5 のカメラモジュールの電源（リチウムイオンのモバイルバッテリ）の詳細。

**2026-11-10 ユーザー決定**: 電池を外し忘れて起動したまま保管し、使いたいときに電池が切れていた。
**操作の無い時間が続いたら外し忘れとみなし、段階的に電力を下げる。**
カメラモジュール（UnitV2）には電源スイッチが無く、電池を挿している限り動き続けるため。

**ユーザーが決めたのは「無操作の時間で判定する・30 分で省電力・30 分かつ機体の無線（`th-rpi-ap`）が飛んでいなければ電源を切る・省電力ではピッチの力を抜いてよい」まで**（電源を切る条件は 2026-11-10 に「60 分」から改めた）。**下の表で「提案」と付けた細部も、同日にユーザーが確認した**（`H-V16` の行の「しばらく続いたら」は 2026-11-10 の追加の提案）。

---

## 1. 外し忘れの判定

| 項目 | 振る舞い |
| --- | --- |
| 無操作 | **カメラモジュールへの操作**（画面・ss-system からのヨー・ピッチ・デジタルズーム・静止画・昇降・設定の変更）が無く、**昇降機も誰からも動かされていない**状態（提案） |
| 数えないもの | 画面を開いているだけ・映像を見ているだけ・状態を読むだけの接続（提案。開いたまま置き忘れた端末で判定が止まらないように） |
| 昇降機の操作を数える理由 | fk-system が昇降機を動かす間は、カメラモジュールの天井の距離が要る（[Spec-module.md](Spec-module.md) §2）。その最中に電源を切らないため（提案） |
| 時間 | **最後の操作から 30 分で省電力（§2）。さらに機体の無線が飛んでいなければ電源を切る（§3）**（ユーザー決定） |

## 2. 省電力（最後の操作から 30 分）

| 項目 | 振る舞い |
| --- | --- |
| 止めるもの | 映像の取り込みと送信。**ピッチのサーボの力を抜く**（ユーザー決定。[Spec-safety.md](Spec-safety.md) §4 の「ピッチはその角度で保つ」の例外）。力を抜く前に、倒れてもよい角度へ動かす（提案。角度は `H-V15`）。そのほか、処理を落とせるものは落とす（提案） |
| 保つもの | 無線・画面・ss-system の口・**天井の距離の測定と昇降部への送信**（提案。昇降部が天井の判定に使うため） |
| 画面 | **省電力中であること**と、**操作すると戻ること・機体の無線が無くなれば電源を切ること**を出す（提案。電源を切る条件に機体の無線が入ったので、残り時間は出さない。2026-11-10） |
| 戻り方 | **操作すれば戻る**（画面・ss-system から。§1 の操作）。映像は取り込みを始め直して出る。**ピッチは、操作で戻ったときに力を入れ、省電力に入る前の目標の角度へ動く**（提案） |
| ss-system | 省電力中かどうかを読めるようにする（提案。静止画の要求が戻りの時間だけ遅れうるため。形はカメラモジュールの口の案で書く） |

## 3. 電源を切る（最後の操作から 30 分、かつ機体の無線が飛んでいない）

| 項目 | 振る舞い |
| --- | --- |
| 条件 | **最後の操作から 30 分経ち、かつ機体の無線（`th-rpi-ap`）が飛んでいない**（＝機体が起動していない。ユーザー決定）。機体が起動している間は、無操作が続いても省電力のまま待つ。省電力中に機体の電源が落ちたら、その時点で切る |
| 無線が飛んでいないとみなす | **一瞬見えないだけでは切らない。見えない状態がしばらく続いたら**とする（提案。続く時間は `H-V16`。AP の一時的な不調で切らないため） |
| `HD-1` との関係 | 無線が飛んでいるかを見るだけで、th-system とは通信しない（[Spec.md](Spec.md) §4 `HD-1` は変えない）。**AP の名前は設定から取り、直書きしない**（[Spec.md](Spec.md) §5） |
| 切り方 | **カメラモジュールが自分で電源を切る**（ピッチの力は抜いたまま）（ユーザー決定） |
| 切ったあと | 昇降部から見るとカメラモジュールが繋がっていない。**天井の距離が無いので、上部モジュールからの上昇は昇降部が拒む**（[Spec-safety.md](Spec-safety.md) §2 #4。今までどおり） |
| 戻し方 | **電池を挿し直す**（提案。電源スイッチが無いため） |
| 電池に残る消費 | 電源を切ったあとも制御基板などが電池を使いうる。**どれだけ残るか、電池が自分で出力を止めるかは実測で確かめる**（`H-V7`・詳細設計 `D-9`） |
