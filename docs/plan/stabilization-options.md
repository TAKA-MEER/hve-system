# stabilization-options — 揺れ対策の各案の詳細

[stabilization.md](stabilization.md) の詳細。**検討メモ（spec ではない）。**

---

## 0. 揺れを測る

**どの揺れか**で効く案が変わる。

| 揺れの種類 | 想像される原因 | 効く案 |
| --- | --- | --- |
| ゆっくり大きく揺れる（数 Hz 以下） | 昇降機が高く伸びた状態で、急停止・機体の走行・人が触れたことで柱がしなる | C（補正）・D（加減速）・A（止めて見る） |
| 細かく震える（数十 Hz） | モータ・ギアの振動 | B（露光）・A。C は追いつかない |
| 画がぐにゃっと歪む | Web カメラのローリングシャッター × 細かい振動 | ソフトでは直しきれない。A・B で軽くなる。**カメラ選び**（グローバルシャッター）か取り付けの防振 |

**測り方（案）**: 先行試作 `../elevator-motor-control` で昇降機を動かし、上端付近に仮の Web カメラを付けて録画する。
ホストで、縮小した白黒画像どうしの**位相相関**（OpenCV の `phaseCorrelate`）でフレーム間のずれを出し、次を得る。

| 測るもの | 何に使うか |
| --- | --- |
| ずれの大きさ（画素・画角に対する割合） | 案 C の補正に要る余白（切り出し枠の外側にどれだけ残すか） |
| 周波数 | 案 B・C のどちらが効くか |
| 急停止から収まるまでの時間 | 案 D の要否。案 A の「直近何秒から選ぶか」 |
| 昇降の高さごとの違い | 高いほど揺れるなら、高さで補正の強さを変える |

## A. 静止画で確認

- `hve_video` が**高解像度の取り込み画像を直近 1〜2 秒ぶん**（仮）手元に持っておく
- 画面の「静止画」ボタンで、その中から**最もぶれていない 1 枚**を選ぶ。尺度は「鮮明さ」（ラプラシアンの分散）と「前後の画像とのずれの小ささ」
- 選んだ 1 枚を**高解像度のまま**画面に出し、デジタルズームで拡大して見る。「ライブに戻る」で戻る
- **既存の仕組みに乗る**: 高解像度で取り込んで切り出す仕組み（デジタルズーム）がそのまま使える
- 保存（`H-S2`）とは独立。保存を決めたら、この 1 枚を保存すればよい
- 注意: 静止画を見ている間も**昇降・ヨー・ピッチのボタンは効く**。ライブでないことを画面ではっきり示す（取り違えると、動いているのに止まって見える）。**昇降のボタンを押したら自動でライブに戻す**のが安全

## B. 露光時間を短く固定

- 自動露出は暗い所で露光時間を延ばし、揺れがそのまま**像の流れ（ぶれ）**になる。露光時間を短く固定すると、1 枚ごとの像は鮮明になる
- V4L2 の設定（`exposure_auto` を手動、`exposure_absolute` を小さく）。カメラによって設定の名前と範囲が違う
- 代わりに暗くなる。ゲインを上げるとざらつく。**照明（`H-S4`）を足すかどうかと一緒に決める**
- 位置のずれ（画面全体が揺れる）は直らない

## C. 電子式手ぶれ補正

- **仕組み**: 毎フレーム、縮小した白黒画像で前のフレームとのずれ（上下左右）を推定し、ずれの軌跡を滑らかにした線との差だけ、**切り出し枠を逆向きにずらす**
- **ズームと一体にできる**: 切り出し枠を「倍率＋ずらし量」で持てばよい。**ズーム 1 倍のときは余白が無いので補正できない**。1 倍でも補正したいなら、最初から画角の外周（例 10%）を捨てて余白にする
- **重さ**: ラズパイ 4 で、320×180 程度に縮めた画像の位相相関なら 1 フレーム数 ms の見込み（要測定）。高解像度の読み込みのほうが重い
- **弱点 1: 遅れて見える。**軌跡を滑らかにするには過去を平均するので、**意図した動き（昇降・ヨー・ピッチ）にも遅れてついてくる**。「映像を見て止める」操作では行き過ぎの原因になる
  - 対策: **昇降・ヨー・ピッチを動かしている間は補正を止める**（カメラ部はどの軸を動かしているか知っている）。止めてから揺れが収まるまでの間だけ効かせる
- **弱点 2: 回転・歪みは直らない。**上下左右のずれだけを直す想定。柱のねじれ（画面の回転）が大きければ回転も推定する（重くなる）
- **弱点 3: 盤面に模様が少ないと推定を誤る。**無地の面ではずれが分からない。推定の確からしさが低いときは補正しない

## D. 加減速

- **動かし始め・止めるときに速度を滑らかに変える**（例: 200 ms かけて目標の速度へ）。急停止で柱を揺らさない
- 昇降: ESP32 で PWM を少しずつ変える。**ウォームギアは電源を切るとその場で止まるので、急停止の衝撃が大きい可能性**がある
- ヨー: ステッピングの加減速はもともと入れるのが普通（脱調も防げる）。これは揺れと関係なく詳細設計に入れてよい
- ピッチ: サーボは deg/s で角度を少しずつ変えている（すでに滑らか）
- **安全の停止（天井・上端・下端・途絶）には使わない。**即座に止める。加減速を掛けるのは**操作者がボタンを離したとき**だけ
- 副作用: 離してから止まるまでが少し延びる（行き過ぎが増える）。案 0 で急停止の揺れが大きいと分かったときだけ採る
