## 1. 昇降部（`WP-LIFT-02`。2026-09-29 に PC でビルドまで確認済み）

用意: ESP32（`firmware/lift` を書き込み、`include/secrets.h` を作る）・MD10C・パワーウィンドウモータ・下端スイッチ（NC 配線）・HC-SR04（**ECHO は分圧して 3.3 V に落とす**）。
操作は PC から `tools/lift_probe.py ws://<ESP32 の IP>/ws`。

**上端の閾値（`LIFT_TOP_MM`）は未設定のまま。上端で止まらないので、上昇は人が見ながら短く行う**（spec [Spec-safety.md](plan/archive/v1/spec/Spec-safety.md) §2 #2a）。

| # | 確かめること | 期待 | 結果 |
| --- | --- | --- | --- |
| 1 | `u`（上昇）・`d`（下降）で動く向き | 上昇で上がる。逆なら `config.h` の `MOTOR_DIR_UP_LEVEL` を反転 | |
| 2 | 上昇中に `lift_probe` の送信を止める（`--stop-sending` 相当の操作） | 約 600 ms（`LIFT_CMD_TIMEOUT_MS`）で止まる。`reason` が `CMD_TIMEOUT` | |
| 3 | `ceil_ok` を false のまま `u`（`lift_probe` の既定は false） | 上昇しない。`reason` が `CEILING` | |
| 4 | 下端スイッチを押した状態で `d` | 下降しない。`reason` が `BOTTOM`。`u` は動く | |
| 5 | 下端スイッチの線を抜いて `d` | 「押されている」とみなし下降しない（NC 配線の断線は安全側） | |
| 6 | HC-SR04 の線を抜いて `u` | 上昇しない。`reason` が `HEIGHT_UNKNOWN` | |
| 7 | 同じ向きに押し続ける | 10 秒（`LIFT_MAX_RUN_MS`・仮）で止まる。`reason` が `MAX_RUN`。反対向きは動く | |
| 8 | 物理非常停止ボタン（th-system） | 昇降機の電源が切れ、その場で止まる（ウォームギア） | |

## 3. カメラ部（`WP-CAM-03`。2026-09-29 に PC の試験まで確認済み）

準備と起動の手順は [使い方.md](使い方.md)。

| # | 確かめること | 期待 | 結果 |
| --- | --- | --- | --- |
| 1 | `/sys/class/pwm/pwmchip0` と `/dev/i2c-1` が出て、アプリから PWM を書けるか | 書ける（2026-09-29 実機で確認: udev 規則は不要。`export` 直後の権限待ちはアプリが 2 秒待つ） | |
| 2 | `i2cdetect -y 1` で SRF02 | 0x70 が見える | **SRF02 は 0x72 に見えた**（0x70 ではない）。`params.toml` の `srf02_i2c_addr` を 0x72 にして天井 1390 mm を読めた（2026-09-29） |
| 3 | 起動したとき | サーボが正面（水平）へ動く。ヨーは回らない | サーボが動く音を確認。UI からピッチを押すと指令角度が動く（2026-09-29） |
| 4 | ヨーを押す・離す | 押している間だけ回る。離すと ULN2003 の LED が 4 つとも消える。脱調・振動が無い。左右の向き（`YAW_STEP_SIGN`・仮） | **動くことのみ確認。** 旧い相の並びでは唸って回らず、隣り合うコイルの順に直して回った。**回転量（約 45°/90°）と左右の向きは未測定・向きは未確定**（2026-09-29） |
| 5 | ピッチ | 上下の向きが正しい。端で押し付けて唸らない（パルス幅は仮） | **動くことのみ確認。**上下の向きは未確定。指令角度は ±22.9° と −1.6° 戻り位置のずれあり。端での唸りは未確認（2026-09-29） |
| 6 | 天井 | 手をかざすと `CEILING_NEAR`。何も無い方へ向けると `OUT_OF_RANGE`（**反射なしの返り値が 0 か**を確かめる）。SDA を抜くと `CEILING_STALE` で、昇降部への `ceil_ok` が false | |
| 7 | 制御の周期 | 天井の測定が 100 ms の指令を遅らせていない | |
| 8 | systemd | 再起動で自動で立ち上がる。`hve-video` も立ち上がる | 自動起動は確認（`hve-camera`・`hve-video` とも active）。**カメラの USB 再認識で映像が空になる**ことがあった（番号でなく名前で選ぶよう修正）（2026-09-29） |

**UI（`http://<ラズパイの IP>/`）の確認（2026-09-29・th-rpi-ap 経由）**: 画面・映像・ズーム・ピッチ／ヨーの長押し・設定画面が開くまで確認。昇降部が未接続のため昇降は未確認。ハードウェアの正確さ（角度・向き）は未測定。
